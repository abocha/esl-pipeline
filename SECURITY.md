# Security Policy

## Supported Versions

This repository is actively maintained on the latest `main` branch.
Security fixes are not backported to historical tags by default.

## Reporting a Vulnerability

Please report security issues privately using a GitHub Security Advisory:

- `https://github.com/abocha/esl-pipeline/security/advisories/new`

Do not open public issues for undisclosed vulnerabilities.

## What to Include

- Affected component/package.
- Clear reproduction steps or proof of concept.
- Impact assessment (confidentiality/integrity/availability).
- Suggested remediation if available.

## Response Expectations

- Initial triage acknowledgement target: within 5 business days.
- Fix timelines depend on severity and reproduction quality.
