# START HERE (Low-Stress Reboot)

If your brain is overloaded, use this file and do only what it says.

## 5-Minute Restart

1. Run: `git status --short`
2. Open: `docs/reference/PRESET_V2_SPEC.md`
3. Open: `docs/playbooks/RESTART_TOMORROW.md`
4. Open: `docs/reference/V1_IMPLEMENTATION_TRACKER.md`
5. Pick one micro-task (30-90 min max).
6. Write: `Today I only need to finish: ____`

That is enough to be back on track.

## One-Session Rule

- Do one meaningful step, not a perfect sprint.
- Stop after one completed micro-task.
- Before stopping, write:
  - What I finished
  - First step next session
  - Current blocker
