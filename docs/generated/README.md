# Generated Docs Index

## Meta

- Audience: maintainers and AI agents needing factual repo inventories.
- Read Time: 2 minutes.
- Authority Level: generated reference router.
- Last Verified Against: 2026-05-12 repo state.
- Owner: founder-maintainer + automation agents.
- Review Cadence: regenerate after docs-topology or route-surface changes.
- Status: `reference`.

## Purpose

- Route readers to generated reference indexes that are cheaper to derive from the repo than to maintain by hand.
- Keep hand-written docs focused on meaning and policy rather than inventory churn.

## Generation Command

- `pnpm docs:generate:indexes`
- `pnpm docs:generate:plans-index` for plan-only lifecycle/index updates.

Docs-gardening health and stale-active artifacts are generated by `pnpm docs:garden`; they are
triage artifacts under `tmp/`, not committed generated references.
Plan lifecycle artifacts are also generated under `tmp/` and explain which plans are editable versus
archived trace.
