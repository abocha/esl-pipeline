## 4. ⚠️ Active Error Patterns (For Correction)
1.  **The "Forbidden Mix" (Perfect + Past Time):**
    *   *Risk:* "I have done it yesterday."
    *   *Fix:* If you say "Yesterday," you must use Past Simple ("I did it").
2.  **Missing "To Be" with Going to:**
    *   *Risk:* "I going to gym."
    *   *Fix:* "I **AM** going to the gym."
3.  **Using "For" for Purpose:**
    *   *Risk:* "I go there **for** relax."
    *   *Fix:* "I go there **to** relax."
