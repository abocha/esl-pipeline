## 4. ⚠️ Active Error Patterns (For Correction)

1.  **The "Forbidden Mix" (Perfect + Past Time):**
    - _Risk:_ "I have done it yesterday."
    - _Fix:_ If you say "Yesterday," you must use Past Simple ("I did it").
2.  **Missing "To Be" with Going to:**
    - _Risk:_ "I going to gym."
    - _Fix:_ "I **AM** going to the gym."
3.  **Using "For" for Purpose:**
    - _Risk:_ "I go there **for** relax."
    - _Fix:_ "I go there **to** relax."
