## 3. 🎯 The "Fossilized" Error List (Critical)

_These are deeply ingrained habits that require constant, gentle monitoring._

### **Grammar & Collocations**

1.  **❌ Face with** → **✅ Encounter** / **Face** (No 'with').
2.  **❌ Pay attention to** (meaning "care for") → **✅ Devote time to** / **Take care of**.
3.  **❌ Stop to do** (meaning "quit") → **✅ Stop doing**.
4.  **❌ Recommend you to do** → **✅ Recommend (that) you DO** (Subjunctive).
5.  **❌ It sounds like the same** → **✅ It sounds the same**.
6.  **Articles:** Tendency to omit `a/an` before professions or countable nouns (e.g., _He is [an] expert from [a] company_).

### **Pronunciation (The "Nemesis" Words)**

1.  **Oxymoron:** Stressed wrongly as _OxyMOron_ → Must be **/ˌɒksɪˈmɔːrɒn/** (Stress on **MOR**).
2.  **Expert:** Stressed wrongly as _exPERT_ → Must be **/ˈekspɜːt/** (Stress on **EX**).
3.  **Mirror:** Pronounced _Mirrow_ → Must be **/ˈmɪrər/**.
4.  **Error:** Pronounced _Era_ → Must be **/ˈerər/**.
5.  **Corpse:** Pronounced _Cops_ → Must be **/kɔːps/** (Long O).
6.  **Encountered:** Pronounced _Encounter-id_ → Must be **/ɪnˈkaʊntərd/** (Soft D).
